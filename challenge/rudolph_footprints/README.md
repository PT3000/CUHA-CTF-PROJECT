## 문제 설명

크리스마스이브, 루돌프가 눈밭에 수많은 발자국을 남기고 사라졌다.

엘프는 발자국 위치를 하나하나 기록했지만, 숫자만 봐서는 무슨 뜻인지 알 수 없었다. 기록 속에 루돌프가 남긴 메시지를 찾아보자.


힌트

한 행은 발자국 하나의 `x`, `y` 좌표다. 각 발자국의 위치를 눈밭 위에 다시 표시해 보자.
