# 마지막 캐럴이 울린 곳

| 항목 | 내용 |
| --- | --- |
| 분야 | OSINT |
| 난이도 | Medium |
| 핵심 개념 | 공개 정보 검색, 기록 대조, 장소 식별 |
| 첨부파일 | [Where the Last Carol](./festival-clue.png) |
| 플래그 형식 | `FLAG{무대코드_공연ID_HHMMSS}` |

## 문제 설명

크리스마스 이브 합창 무대의 중계 화면 한 장이 기록관에 남았습니다. 폭설로 인해 정류장과 공연 일정이 바꿔었습니다. 오래된 안내도와 정정 공지가 함께 남아 있었고 중계 화면에도 현장 시각과 다른 시계가 찍혔습니다, 이 장면이 어디에서, 현장 시각으로 언제, 어느 공연 중에 찍현는지 공개 자료를 대조해 확인하자.

## 문제 안내

- `index.html`을 열면 중계 캡처, 축제 안내도, 시설·교통 공지, 공연 자료실, 중계 기록 등 제공 자료들을 `index.html`에서 볼 수 있습니다.
- 중계 화면에 표시된 시각은 송출 시각입니다. 중계 기록을 확인해 실제 촬영 시각을 구하세요.
- 공연 ID에는 촬영 당시 관객 앞에서 실제로 진행 중이던 공개 합창의 ID를 사용하세요.
- 촬영 시각은 한국 표준시(KST)로 환산한 뒤 `HHMMSS` 형식으로 적으세요. 예를 들어 `20:50:09`는 `205009`로 적습니다.
- 무대 코드, 공연 ID, 촬영 시각을 순서대로 이어 붙여 플래그를 제출하세요.
