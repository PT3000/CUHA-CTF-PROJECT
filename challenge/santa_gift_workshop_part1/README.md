# 산타의 선물 공방

| 항목 | 내용 |
| :--- | :--- |
| 분야 | Crypto |
| 난이도 | Medium |
| 핵심 개념 | XOR 비트 연산, ASCII, 바이트, 16진수 |

| 플래그 형식 | `xmas{...}` |

## 문제 설명

크리스마스를 앞두고 산타의 선물 공방은 선물 포장으로 한창 바쁘다.

하지만 엘프가 포장 목록을 암호화한 채 퇴근해 버렸다.
작업대 위에 놓인 종이에는 다음과 같은 메시지가 적혀 있다.

> 목록의 모든 바이트를 같은 열쇠로 잠갔어.
> 열쇠는 42야.
> 같은 열쇠를 한 번 더 쓰면 목록을 읽을 수 있어.

공방 문이 닫히기 전에 암호화된 포장 목록을 복원하자!

## 문제 안내

- 암호화에 사용된 키는 10진수 `42`(16진수 `0x2A`)입니다.
- `encrypt.txt`의 16진수 두 자리는 하나의 바이트를 나타냅니다.
- 원문은 ASCII 텍스트입니다.
