# 루돌프의 비밀 암호

| 항목 | 내용 |
| --- | --- |
| 분야 | Crypto |
| 난이도 | 중 |
| 핵심 개념 | 비즈네르 암호, 반복 키, 다중 치환 암호 |
| 첨부파일 | [encrypted.txt](./encrypted.txt) |
| 플래그 형식 | `Xmas{...}` |

## 문제 설명

산타가 루돌프에게 비밀 배송 명령을 전달했다. 통신 기록에는 암호화된 배송 편지와 루돌프가 남긴 쪽지가 들어 있었다.

> 알파벳을 밀어내는 거리는 매번 달라.  
> 열쇠가 끝나면 처음부터 다시 시작하면 돼.  
> 열쇠는 내 이름이야.

통신 기록에 적힌 수신자 이름은 `RUDOLPH`다. 쪽지를 단서로 암호문을 복호화해 배송 명령을 확인하자.

## 문제 안내

영문 알파벳에만 암호화를 적용했다. 대소문자는 유지했고, 공백, 줄바꿈, 중괄호, 밑줄 등의 위치에서는 키를 넘기지 않는다.
