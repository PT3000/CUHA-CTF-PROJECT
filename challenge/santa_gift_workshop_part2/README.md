# 산타의 선물 공방 (상)

## 문제 정보

| 항목 | 내용 |
| :--- | :--- |
| 분야 | Crypto |
| 난이도 | 상 |
| 핵심 개념 | XOR 비트 연산, ASCII, 바이트, 전수 탐색 |
| 첨부파일 | `prob.py`, `encrypted.txt` |
| 플래그 형식 | `Xmas{...}` |

## 문제 설명

자정이 가까워지자 산타의 선물 공방에 마지막 선물 목록이 도착했다.

하지만 이번에는 엘프가 암호화에 사용한 열쇠의 값을 적어 두지 않았다.
작업대 위에 놓인 종이에는 다음과 같은 메시지만 남아 있다.

> 이번에도 모든 바이트에 같은 열쇠를 썼어.
> 열쇠는 0부터 255 사이야.

암호화된 목록을 읽을 수 있는 열쇠를 찾아 선물을 제때 배달하자!

## 문제 안내

- 모든 바이트에 동일한 8비트 키로 XOR 연산을 적용했습니다.
- 산타의 선물 공방 (하)에서 사용된 키와는 다른 키입니다.
- `encrypted.txt`의 16진수 두 자리는 하나의 바이트를 나타냅니다.
- 원문은 ASCII 텍스트입니다.
