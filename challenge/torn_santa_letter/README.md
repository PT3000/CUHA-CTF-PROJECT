## 문제 설명

크리스마스이브, 산타 앞으로 온 편지를 스캔했다. 정사각형으로 저장한 편지였는데, 다시 열어 보니 위쪽만 남아 있다. 편지의 아래쪽을 복구해 마지막 줄에 적힌 비밀 코드를 찾아보자.

필요한 힌트는 [hints.txt](./hints.txt)에서 골라 읽을 수 있다. 플래그 안에서 동그랗게 보이는 `0`은 숫자다.
