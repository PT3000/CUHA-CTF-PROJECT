# 미쿠의 크리스마스

| 항목 | 내용 |
| :--- | :--- |
| 분야 | Misc |

## 문제 설명

크리스마스이브, 산타 옷을 입은 미쿠가 선물과 함께 그림 한 장을 남겼다.

선물 주머니에는 다음과 같은 짧은 메모가 달려 있었다.

> 내가 남긴 쪽지는 색깔의 가장 작은 차이 속에 있어.

평범해 보이는 그림 속에는 미쿠가 남긴 비밀 메시지가 숨겨져 있다.

원본 PNG의 픽셀을 분석하여 미쿠가 숨긴 메시지를 찾아보자!

## 문제 안내

- 첨부된 원본 PNG 파일을 그대로 사용합니다.
- 이미지의 크기 변경, 압축 및 형식 변환에 주의합니다.
- 문제 풀이에 필요한 개념은 `hints.txt`에서 확인할 수 있습니다.
- 힌트는 필요한 항목만 선택하여 확인하는 것을 권장합니다.
