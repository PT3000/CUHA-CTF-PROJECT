## 문제 설명

크리스마스 야간 근무를 앞두고 산타의 비밀 창고에 도착했다. 입구의 경비원 ELF-01은 당직 인수인계 내용을 알고 있다. 경비원에게 말을 걸어 첫 근무에 필요한 단서를 모으자. 창고 안의 배송 기록과 창고 퍼즐을 따라가면 마지막 암호문을 찾을 수 있다.

경비원이 응답하지 않으면 대화창에서 **ELF-01의 인수인계 수첩**을 펼쳐 보자. 진행 상태는 브라우저의 방문 쿠키에 연결된다. 같은 브라우저에서 이어서 플레이할 수 있다.

## Docker로 실행하기

이 디렉터리에서 다음 명령을 실행한다.

```sh
docker compose up --build -d
```

이 PC에서는 [localhost:8008](http://localhost:8008/)로 접속한다. 다른 기기에서는 서버의 IP 주소나 도메인에 포트 `8008`을 붙인다. 기본 설정은 모든 네트워크 인터페이스에서 접속을 받는다. 이 PC에서만 열려면 실행 전에 `SANTA_BIND` 환경 변수를 `127.0.0.1`로 설정한다.

| 운영 환경 변수 | 용도 |
| --- | --- |
| `SANTA_FLAG` | 운영자가 정한 대회 정답. 미설정 시 연습용 값 `xmas{practice}`를 사용한다. 중괄호 안에는 영문자, 숫자, 밑줄을 1~100자까지 쓸 수 있다. |
| `MINDLOGIC_API_KEY` | 선택 사항. 배포 환경의 비밀 변수로 제공하면 ELF-01의 실시간 대화를 사용할 수 있다. 키 없이 실행해도 첫 질문 뒤 인수인계 수첩에서 단서를 얻을 수 있다. |

빈 데이터 볼륨에서는 첫 실행 시 실습 직원 계정을 준비한다. 기존 볼륨의 직원 계정 설정은 유지한다. 진행 기록은 Docker의 `workshop-data` 볼륨에 저장하며 `docker compose down` 후에도 보존한다.
